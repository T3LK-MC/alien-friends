# 👽 Alien Friends

A cozy little Fabric mod that brings some extraterrestrial charm to your Minecraft world — glowing alien ores, (sometimes) helpful friends, and a weird currency from outer space.
This is my first ever mod project to learn how to make my own mods and implement them in the game.

## ✨ What's inside

- 🪙 **Zib Coin** — a mysterious gold coin with an alien face, because currency from space has to look the part
- 🥚 **Zab Zab Spawn Egg** — summon a Zab Zab and see what happens
- 💎 **Zib Steel Ore** — a glowing ore vein hiding in the depths, giving off a faint light of its own
- 🧱 **Block of Zib Steel** — for when you've mined more than you know what to do with

More alien oddities are on the way — this project is still very much growing.

## 🚀 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for Minecraft **1.21.1**
2. Grab the [Fabric API](https://modrinth.com/mod/fabric-api) — required
3. Drop the mod `.jar` into your `mods` folder
4. Launch and enjoy the visitors from another world 👽

## 🛠️ Building from source

```bash
git clone https://github.com/T3LK-MC/alien-friends.git
cd alien-friends
./gradlew build
```

The built jar will show up in `build/libs/`.
